## 任务信息
- 任务名称：ui-home-and-profile
- 创建日期：2026-01-14
- 阶段：Align（共识确认）

## 明确需求（最终版）
### 主页视觉与结构
- 保留现有“进度卡 + 分组卡列表”信息结构，仅做视觉改版，贴近 IMG_4620.PNG。
- 顶部标题区改为“图标 + 标题 + 数量”的样式，右侧圆形“+”按钮。
- 增加筛选胶囊（未完成/全部/隐私空间/已完成），并支持真实筛选功能。
- 进入 App 默认显示“未完成”筛选。
- 背景为浅灰、卡片为白色、圆角与阴影更柔和，整体密度更轻。

### 筛选与隐私空间
- 未完成：仅显示未完成事项，并展示对应分组。
- 全部：显示全部事项（包含隐私事项）。
- 隐私空间：仅显示隐私事项，进入与查看需通过 Face ID 验证。
- 已完成：仅显示已完成事项（包含隐私事项，但若未解锁仍需验证）。
- 隐私事项不显示在 Live Activities（锁屏/灵动岛）中。
- 需要提供“设置/取消隐私”入口（例如任务行的上下文菜单）。

### Tab 结构
- 使用系统 TabView 承载“事项/我的”两页，并自定义外观以贴近胶囊样式。
- 默认进入“事项”页。
- 隐藏系统 TabBar，仅保留自定义胶囊样式。

### “我的”页面
- 版式参考 IMG_4622.PNG：顶部问候语 + 会员按钮 + 分区卡片列表。
- 列表项需要可点击行为与跳转（可为本地占位页面，不接入网络/账号系统）。
- 实时活动权限项需要检测状态，未开启时点击跳转系统设置。
- 自定义锁屏卡片支持设置锁屏实时活动显示条数与背景透明度。
- 默认语言项点击跳转系统设置。
- 给好评项触发评分弹窗。
- 反馈项跳转 https://qingtengstudio.com/。

### 多语言
- 支持中文 + 英文（本地化文案）。

## 技术实现共识
- 继续使用 SwiftUI / SwiftData / ActivityKit 现有架构。
- 引入 LocalAuthentication（Face ID）进行隐私解锁。
- 数据层新增隐私标记字段（建议在 TaskItem 上新增 `isPrivate: Bool`，默认 false）。
- Live Activity 内容生成时过滤掉 `isPrivate == true` 的任务快照。
- 主页筛选逻辑在 UI 层实现，不改变持久化结构的排序与同步逻辑。

## 交互与行为细节
- 顶部“+”按钮仅执行“新建分组”，不弹出菜单。
- 进入“隐私空间”或尝试展示隐私事项时触发 Face ID。
- Face ID 失败或不可用时提示并保持隐私内容隐藏。
- 解锁状态仅在当前会话内有效（App 冷启动后重新验证）。
- 默认筛选为“未完成”。

## 验收标准
1. 主页视觉样式接近 IMG_4620.PNG，保持原有数据结构与功能。
2. “未完成/全部/隐私空间/已完成”筛选可用，且默认进入未完成。
3. 隐私事项不出现在 Live Activities 内容中。
4. Face ID 验证可用；未验证时隐私事项不可见。
5. 顶部“+”按钮创建新分组。
6. 底部 Tab 可切换“事项/我的”，外观符合参考图风格。
7. “我的”页面列表项可点击并跳转到占位页面或触发本地动作。
8. 实时活动权限未开启时点击跳转系统设置。
9. 自定义锁屏卡片设置生效（显示条数/透明度）。
10. 默认语言入口跳转系统设置。
11. 评分入口触发评分弹窗。
12. 反馈入口打开 https://qingtengstudio.com/。
13. 中文/英文本地化生效。

## 边界与非目标
- 不接入会员系统/登录系统/网络接口。
- 不调整 SwiftData 模型关系结构，仅新增必要字段。
- 不改动 Live Activity 生命周期流程，仅过滤隐私事项。

## 风险与注意事项
- Face ID 权限/可用性需兼容无生物识别设备（fallback 为系统设备验证）。
- Live Activity 内容大小限制需保持（过滤隐私事项可降低负载）。
