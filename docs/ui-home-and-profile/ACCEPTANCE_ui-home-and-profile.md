## 完成内容摘要
- 主页视觉改版：顶部标题、筛选胶囊、卡片样式更新，保留“进度卡 + 分组卡列表”。
- 新增 TabView：事项/我的 双页结构，自定义胶囊样式底部栏（隐藏系统 TabBar）。
- 新增“我的”页面：分区列表 + 可点击跳转占位页。
- 隐私事项支持：TaskItem 增加 `isPrivate`，筛选与 Face ID 解锁。
- Live Activity 过滤：隐私事项不进入 Live Activity。
- 多语言：新增中文/英文本地化文件与 Face ID 说明本地化。
- 新增“未完成”筛选并设为默认入口。
- 新增锁屏实时活动设置：显示条数与透明度。
- “我的”页点击项支持跳转、评分、设置与外链。
- 修复筛选胶囊文字换行，统一单行展示。
- 隐私空间独立展示，私密分组在隐私空间内创建与查看。
- 锁屏卡片设置变更可即时刷新并读取正确默认值。
- “我的”页更新为 Logo 问候、会员入口迁移、新增关于入口。
- 新增订阅页（免费/月度/年度）与软件说明页（含实时活动提示与指示图）。
- 新增底部署名、作者链接与版本号展示。
- “我的”页问候与说明文案左对齐，陪伴天数实时计算。
- 订阅页接入 StoreKit Manager 展示订阅信息。
- 会员权益限制：隐私空间与锁屏卡片仅会员可用，免费版条数上限为 3。
- 订阅页升级为现代卡片风格并隐藏产品 ID。
- 新增锁屏实时活动分组选择，并限制免费版仅显示 1 个分组。
- 订阅页补充合规说明、周期与取消提示，并更新用户服务链接。
- 应用英文名调整为 FocusScreen 并同步文案。
- 修复设置页与订阅页英文本地化显示。
